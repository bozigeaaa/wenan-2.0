# Light-Steel Script Pattern

Read `../../references/generation-trigger-registry.md` before drafting. It is the authority for public generation triggers, information relationships, hook timing, conditional placement, oralization, length review, promise validation, ending conditions, and deduplication. This file adds only the evidence and risk boundaries specific to thin-walled light-steel structures, envelopes, selection, and Saudi use.

Comparisons between light steel, packed boxes, or another system must match use, span, duration, configuration, and performance basis. Company or product evidence may appear only when it helps fulfill the content promise; it does not require a separate section.

## Domain Checks

- Verify steel grade, thickness, section, coating, insulation, thermal, fire, acoustic, wind, seismic, span, load, packing, installation, and reuse claims from the appropriate source.
- Do not compare isolated parameters from incompatible systems.
- Treat heat, sand, wind, coastal exposure, and camp life as conditional design inputs, not universal conclusions.
- Current production, stock, schedule, delivery, and installation claims require current confirmation.
