# Fire Topic Library

Pick one content promise per video. The items below define evidence scopes, not title wording, question forms, or script structures.

只在 `generation-trigger-registry.md` 打开植入条件分支时，才检查公司或产品是否有证据并能帮助完成同一判断变量；通过才写入。

## Recommended Single-Point Topics

### 1. Space Use And Fire-Risk Zoning

Evidence scope: whether different space uses require different fire-risk zoning or configurations.

Use when explaining:
- Different camp spaces have different fire risks.
- Kitchen/dining, dormitory, office, warehouse, and equipment rooms should not be treated as one generic box.
- Company/product mapping: when confirmed by project requirements, use Eastern Camel's relevant layout, configuration, or delivery capability to explain how the zoning decision is carried into the project.

### 2. Fire Separation And Fire-Resistance

Evidence scope: how interfaces and separation affect the supported fire-resistance judgment.

Use when explaining:
- Wall, roof, partition, door, and opening positions.
- Fire-resistance is about the whole interface, not only a board name.
- Company/product mapping: when confirmed by project requirements, map Eastern Camel wall/roof/door configurations to the same separation question; do not turn it into a catalog list.

### 3. Firestopping At Joints And Penetrations

Evidence scope: whether joints and penetrations have matching firestopping evidence and methods.

Use when explaining:
- Joints, seams, cable penetrations, and pipe penetrations are inspection blind spots.
- Firestopping materials and methods must match the report/specification.
- High-risk: UL/ASTM names must be verified before use.

### 4. Civil Defense Evidence Chain

Evidence scope: consistency among drawings, BOQ, material reports, and site installation.

Use when explaining:
- The issue is not whether people say "fireproof"; it is whether documents and site reality match.
- Good for professional trust content.
- Company/product mapping: use the relevant Eastern Camel product documents or installation method to explain the same consistency question when those materials are confirmed.

### 5. Egress And Exit Path

Evidence scope: how the applicable project conditions govern egress and exit-path checks.

Use when explaining:
- Means of egress, exit paths, doors, signage, emergency lighting.
- Do not invent fixed widths or distances without project data.

### 6. Firefighting And Alarm Systems

Evidence scope: which verified use, area, occupancy, and drawing conditions govern protection-system requirements.

Use when explaining:
- Fire protection systems depend on usage, area, occupancy, and drawings.

## Splitting Rule

If a draft combines several independent promises from the scopes above, split them into separate topics. The current script keeps only the promise its title commits to; it does not need to preview the rest.
