# Sanitary Unit Fact-Check Rules

Sanitary-unit scripts are risky because product parameters, hygiene/compliance claims, and competitor comparisons can easily become exaggerated. The goal is not to avoid numbers. The goal is to verify each number and use only the parameters that directly support the script's single point.

## High-Risk Facts

Use these when confirmed by local sources, user confirmation, or reliable current sources. Do not write them as facts before verification:

- K-series model names and combinations: KS-S1, KS-S2, KS-W1, KS-W2, KS-W1S1, KS-W1B1, KS-W1B1E1, KS-B2T1, etc.
- External dimensions, packing dimensions, container loading quantity, weight, capacity, or footprint.
- Install time, assembly manpower, delivery time, local stock quantity, and emergency deployment speed.
- Price, maintenance cost, cleaning frequency, lifespan, replacement cycle, or ROI.
- Materials: 304 stainless steel, ceramic, wall panel material, frame material, seals, drainage interface, ventilation configuration.
- Odor, waterproofing, anti-corrosion, anti-rust, high-temperature resistance, antibacterial, or "easy cleaning" claims.
- Saudi labor/camp sanitation rules, inspection requirements, fines, client acceptance, or compliance outcomes.
- Competitor names, market share, current mainstream Saudi alternatives, or product performance comparisons.
- Company/factory facts: local factory, local stock, delivery time, capacity, and `15000㎡` factory area.

## Parameter Use

Before writing a parameter, run two checks:

1. **Truth check**: Where is this exact parameter confirmed?
2. **Relevance check**: Which locked decision variable or required answer does this parameter support?

Keep it if it is both verified and directly answers the current script's single point.

Examples:

- A script about odor may use ventilation, sealing, drainage, or cleaning-access parameters if confirmed.
- A script about urgent deployment may use packing dimensions, assembly time, stock, or logistics parameters if confirmed.
- A script about model selection may use model combinations and usage scenarios if confirmed.
- A script about corrosion/maintenance may use 304 stainless steel or anti-corrosion details if confirmed.
- Do not include packing size in an odor script unless the point is deployment, not smell.
- Factory area and `15000㎡` only fit local manufacturing scale, production capacity, or delivery certainty. Do not use them in scripts about odor, drainage, ventilation, model selection, cleaning, floor material, or maintenance unless they directly answer that one point.

## Conflict Handling

If local files conflict:

1. Check `knowledge/钧瀚产品优势分级分类总表_v4.xlsx` for conflict records.
2. If still unresolved, ask the user to confirm or avoid the exact number.
3. Do not choose a value because it sounds stronger.

Known conflict-prone areas:

- Mobile toilet price口径.
- Mobile toilet installation time and required manpower; 没有当期确认资料时不写具体时长或所需人手。
- Brand naming: 钧瀚科技, TBOX, ModCamp, 东方骆驼, EASTERN CAMEL, ALJMAL.
- Model names and product naming across brochures.

Do not convert an unverified or conflicting exact claim into a generic finished claim. Omit it. A narrower proposition about deployment, material behavior, inspection relevance, or odor management may be used only when the evidence itself directly supports that proposition and its applicability boundary. A qualifier about configuration or site conditions does not repair missing evidence.

## Compliance And Policy Claims

If mentioning Saudi sanitation rules, camp inspections, labor accommodation standards, fines, or government enforcement:

- Browse current reliable sources or use confirmed local knowledge.
- Do not invent legal article numbers, fine amounts, or agency actions.
- Do not promise inspection approval.
- 只写已核实的主管要求、适用对象、适用条件和实际控制事项；无法核实这些边界时不写该合规主张，也不用“按当地要求”等泛化句代替证据。

## Competitor And Market Claims

If comparing with current Saudi market alternatives:

- Browse current reliable sources before writing current-market claims.
- Prefer comparing solution types: basic portable toilet, containerized sanitary unit, modular shower/toilet unit, permanent bathroom, imported vs local stock.
- Do not accuse competitors of non-compliance, bad materials, or poor hygiene without evidence.
- Compare only verified decision dimensions such as applicability, maintenance burden, deployment capability, or operating cost. Do not turn those dimensions into a stock contrast or blanket inferiority claim.

## Permitted Claim Scope

- State an operational or inspection consequence only when evidence links the sanitary facility to that management outcome.
- Explain odor or backflow through verified contributing mechanisms; do not infer absence of odor from one component or feature.
- Compare models using verified occupancy, use, maintenance, footprint, or transport variables that affect the locked decision.
- Use brochures for the facts they actually establish. Obtain exact model parameters from a confirmed parameter source rather than treating source hierarchy as a reusable spoken line.
