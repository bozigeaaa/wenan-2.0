# Professional-Knowledge Script Pattern

Read `../../references/generation-trigger-registry.md` before drafting. It is the authority for public generation triggers, information relationships, hook timing, conditional placement, oralization, length review, promise validation, ending conditions, and deduplication. This file adds only the evidence and risk boundaries specific to professional mechanisms, procedures, terms, and decision boundaries.

Keep codes, standards, authority guidance, project specifications, common practice, and inference distinct. Company or product content may appear only when a verified mechanism helps fulfill the same professional content promise.

## Domain Checks

- Define necessary terms in spoken language without diluting legal or technical scope.
- Verify exact standards, clauses, approvals, test methods, parameters, times, and authority conclusions from primary material.
- Separate mandatory requirements from project preferences and common practice.
- Do not expand basic knowledge into a long report when no non-obvious conclusion is supported.
