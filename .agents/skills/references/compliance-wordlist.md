# 违禁 / 夸大词清单（表达层红线）
> 用途：定稿前的表达层自查。本清单聚焦"不能写什么词、什么调门"，配合 AGENTS.md「事实与调门红线」使用。它不是平台合规保证；涉及具体平台或地区规则时，仍需核对当前官方要求。

## 一、绝对化 / 无法证明的承诺（禁用）
| 词 / 说法 | 原因 | 处理 |
| --- | --- | --- |
| 100% 安全 / 绝对防火 / 一定通过验收 | 无法证明的绝对承诺，夸大宣传 | 删除；只有证据明确支持的具体性能、条件和范围才可另写 |
| 完全不返臭 / 永远不生锈 / 零维护 | 绝对化产品承诺 | 删除；不得换成另一句未经证明的效果描述 |
| 第一 / 最省 / 最好 / 行业唯一 | 绝对化排名（无依据） | 有依据时写清楚范围，无依据不写 |
| 保证 / 确保 / 承诺（未核实的能力） | 把可能性写成确定性 | 删除或停止核验；免责句不能代替证据 |
| 一定 / 必然（用于结果） | 过度确定 | 删除；只有来源本身支持概率或条件关系时才按该强度写 |

## 二、恐吓式 / 制造焦虑的调门（禁用）
- "不这样做就停工""会出大事""锁死""鬼门关"
- "所有人都不知道""行业内幕""惊天内幕"
- 把普通麻烦夸大成致命后果，或把"可能"写成"已经"
- 标题调门必须与正文后果量级匹配

## 三、编造类表达（禁用）
- 虚构客户评价："某客户反馈很好""客户都说"
- 虚构案例/项目经历/审批结果/处罚
- 虚构数字、比例、节省额、库存量、交期
- 把"典型场景/假设"写成"已发生事实"

## 四、贬损类表达（禁用）
- 贬低沙特本地供应商、本地施工方、竞争对手
- "二道贩子""小厂没库存""都在偷工减料"
- 拿"国内方案"贬低为低价劣质

## 五、平台审核风险点（建议定稿前检查）
- 夸大功效、绝对化承诺 → 易被限流或下架
- 未经授权的客户案例、项目名称、现场照片 → 隐私与授权风险
- 断章取义的标题/封面（正文不兑现） → 内容质量与举报风险
- 涉及处罚、停工、罚款等具体后果 → 必须有依据，否则不写
- 医疗、安全、法规结论类表述 → 不替代官方或专业判断，保留来源

## 六、字眼与来源强度匹配（表达层自查）
**结论的确定程度必须和来源强度匹配**：来源能撑住，按它实际证明的强度和边界写；没有证据就删除或停止。只有来源本身直接支持更窄或更弱的命题，并同时支持其适用条件时，才能改写为该命题；不能用条件词、免责句或弱化词修复缺失证据。
- "要求 / 必须" 与 "建议 / 宜" 代表不同证据强度。只有明确来源证明相应主体（法规、业主、图纸、审批路径）确实作出该要求或建议时才写；没有来源时不把规范结论改装成泛化建议。
- "明确把……列为 / 明确要求"类重大断言必须有可查的原始来源，且正文不得超出原文支持的对象、条件与范围。来源只支持讨论范围或适用可能性时，只能在这些边界内陈述。
- "很可能 / 可能"也属于事实强度，必须由证据或明确标注且有依据的推断支持，不能作为未核实强结论的修补词。
- 警惕"过度解读"：把"同一套许可逻辑"解读成"必须同时审批"、把"列入讨论范围"解读成"强制要求"，都是越界。每个强字眼都要问一句"来源原文到这个程度了吗"。
## 使用方式
- 本清单是所有完整文案、标题、分镜定稿前必读的表达层红线。
- 发现命中禁用词时：不是简单换同义词，而是判断结论本身有没有依据；没有证据就删除或停止，有证据则只按来源实际支持的强度、条件和范围表达。
