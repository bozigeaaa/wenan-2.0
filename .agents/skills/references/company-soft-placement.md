# 公司软植入规则

## 适用范围

详细植入资格不是每篇稿的默认步骤。仅当满足以下任一触发条件时，才使用本规则：用户明确要求公司或产品、产品本身是主题，或新闻流程已选定产品。脚本准备出现东方骆驼、深圳钧瀚、品牌名称、公司产品或公司能力时，也不得绕过这三个触发条件。

检查不等于必须植入。触发后，公司与产品只有在帮助回答 `generation-trigger-registry.md` 锁定的同一判断动作或变量时才进入正文。

## 植入资格

进入触发分支后，同时确认：

1. 语义承诺的对象与场景、判断动作或变量、所需答案和适用边界已经明确；
2. 产品或公司业务已由资料确认，且其机制、比较依据、实施责任或明确不适用边界能帮助回答同一判断动作或变量，而非只讲同项目、同产品或同领域的相邻结论；
3. 写入的每项事实有原始资料、证据台账或用户确认支撑，实时变量有当期确认，且用户没有明确要求不写公司和产品。

三项成立才进入植入设计。资格不成立时，先判断能否在不改变语义承诺和事实的前提下换一个真实角度；仍不成立就停止植入。不得为了保留品牌补造痛点、案例、项目关系、现场画面或产品需求。

产品本身是标题对象、选型对象或本期内容承诺时，产品知识可以直接进入；公司名称和公司能力仍分别接受事实与同一判断变量的相关性检查。

### 新闻核验卡例外

新闻核验卡已经完成“新闻事实 → 项目判断 → 用户选定产品”的适配时，所选产品可以进入正文。确认该产品属于公司真实业务后，东方骆驼可随产品自然出现一次，不再重复证明公司与新闻项目存在关系，也不要求公司证据桥。

该例外只支持公司名称与所选产品的业务对应关系。它不支持公司参与、供货、安装或服务该新闻项目，也不支持库存、交期、生产、配送、安装、售后等具体能力；这些事实仍须逐项核验，并且所选产品仍要帮助回答新闻内容承诺锁定的同一判断变量。

## 选择承担的角色

植入前先选择公司或产品在同一判断变量的答案中承担什么角色，只选本题需要的部分：

- 机制：产品特性解释为什么某个判断成立。
- 判断标准：公司实际做法提供一个客户可核对的口径。
- 责任节点：公司在生产、配送、安装、资料或维护中的已核实职责，补全责任链。
- 证据：经核实的公司事实直接证明本期结论。
- 选择对象：产品就是本期比较或配置对象。

如果说不清它怎样帮助回答判断变量，说明植入仍只是名称。

## 表达与位置

- 出现次数、句数、位置和顺序由信息关系决定，不设固定“背景—担忧—能力—产品”结构，也不要求固定在中段或结尾。
- 公司内容可以与机制写在同一段，也可以独立成段；段落形式不是植入资格。对段内实质性公司主张逐项检查：它须帮助回答同一判断变量、提供所需证据或解释证据为何改变答案。自然过渡、口播停顿和必要指代本身不要求再增加一项专业事实，但也不能借此塞入公司介绍、口号或优势清单。
- 关系在上下文中已经清楚时直接说事实；可能误读时用最短连接补足。不要求每次公司出现都紧贴固定承接句。
- 公司和产品出现后继续回答同一判断变量，不扩写公司简介、不顺带罗列其他产品、不追加无关联系方式。
- 标题只有在正文会兑现对应公司或产品承诺时才出现名称；标题未出现不构成正文必须露出的理由。

## 事实与营销边界

- 公司经营范围、产品范围和稳定能力以公司资料及证据台账为事实底座。
- 参数、认证、数据、案例、合作关系、库存、产能、交期、排产和安装安排等硬事实逐项核验，不用营销语气代替证据。
- 保留项目用途、图纸、业主要求、配置、审批路径等必要条件，不把可能性、比较判断或风险降低写成确定结果。
- 库存、交期、排产、具体配置和现场人员安排等实时变量，没有当期确认资料时不写。不得先写未经核实的卖点，再用免责句兜底。
- 不自行补造客户反馈、项目结果、数量、比例、客诉数据、竞品缺陷或绝对承诺。

## 广告剥离测试

广告剥离是对文案副本做的临时审校，不删除知识库、证据台账或原始资料。

科普、新闻、产品种草、产品选型及其他已触发植入分支的文案依次检查：

1. 移除品牌名、口号和无关公司介绍，保留本题必要的产品知识。
2. 如果答案完全不变，品牌内容没有承担信息角色，应删除或重写。
3. 如果语义承诺本身也随之无法理解，正文过度依赖广告语，应先把行业对象和判断说清。
4. 如果移除的是有证据的机制、责任节点或判断标准，答案确实变弱，植入有效。

品牌背书或公司案例以公司为主题，不执行名称剥离；改为检查每项公司事实有证据、没有扩大适用范围，也没有虚构项目参与或效果。

测试失败时先重写信息关系；仍不能让公司或产品帮助回答同一判断变量，就停止植入，而不是增加铺垫。

## 口语审查

植入句出现以下症状时才重写：

- 从行业解释突然切成公司介绍；
- 连续列出多个优势、参数或服务；
- 删除公司名后只剩空泛赞美；
- 使用“欢迎咨询、联系我们、点击头像”等与本题动作无关的收尾；
- 第一人称经验暗示了未经证实的客户、项目或现场经历；
- 为了“自然”反复添加“我们怎么做、我们一般会、这也是我们常说的”等固定句式。

完整口播的 CTA 按 `expression-craft.md` 执行，结尾给一个与本题相关的动作；用户明确要求无 CTA 时省略。互动不能新增公司服务、交付或效果承诺，也不能替代正文中的植入资格。
