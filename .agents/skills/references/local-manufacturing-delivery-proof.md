# 本地制造型交付能力规则

## 目的与适用范围

本规则用于面向在沙特经营、投资或准备进入沙特的中文项目决策者，说明“本地有销售窗口”与“本地能够承担制造和交付责任”之间的差异。

仅在以下场景优先使用：

- 航运、港口、船期、进口、跨境采购或国际物流；
- 到场、仓储、配送、卸货、安装、交付周期或责任边界；
- 品牌背书、供应商比较、产品选型后的履约与后续服务；
- 用户明确要求突出本地制造、本地库存或本地服务能力。

不适用于以消防、审批、技术机理、材料性能或营地运营为核心的问题；除非“本地履约责任”本身就是该问题已核实的直接答案。

## 核验维度

内容应从客户的核验动作出发，而非直接给竞争对手贴标签。按当前主题选择一至两个维度，不机械罗列：

1. **生产主体**：谁实际生产或组织本地制造，谁对产品工艺与配置负责。
2. **常规品备货**：常规产品能否按当期项目需求调配；不把常规品备货说成所有型号永久现货。
3. **配件供应**：配件由谁生产或供应，后续补件的责任接口由谁承担。
4. **配送、安装与验收**：谁负责从本地仓储或生产端到现场的配送、卸货、安装协调、项目资料与交付记录。
5. **后续变更和维护**：配置变化、补件、维护或售后时，项目方由谁对接。

## 公司事实与项目变量

已由公司确认的稳定能力，可作为品牌背书的事实基础：沙特本地制造、常规品备货、配件自产或供应能力、本地配送与安装交付、项目全程协同，以及已确认的工厂规模、月产能和安装团队口径。

以下属于实时项目变量，没有当期确认资料时不写：具体型号是否现货、实际库存数量、具体交期、实际安装人数、项目配置、排产和配送安排。不得先写未经核实的卖点，再用免责句兜底。

使用具体数值时，要说明其对应的是工厂面积、月产能、团队规模或项目配置中的哪一项；不得把不同口径混写为同一个“规模”结论。

## 标题与表达规则

- 先继承本稿已锁定的语义承诺；只有本地制造或交付责任会直接改变其判断动作、必须答案或适用边界时，才进入标题和正文；不将所有交付热点改写成同一类能力追问。
- 只有话题已明确涉及进口、跨境采购或国际船期时，才把中国端、海外来源或跨境路径写入标题或正文。
- 禁用“二道贩子”等竞争对手身份标签，也不直接声称对手的工厂规模、库存状态或履约能力存在问题。需要比较供应模式时，只写有证据的责任差异，并且该差异必须改变当前语义承诺的答案或边界。
- 不把“本地制造”硬植入消防、审批、材料或技术科普。热点负责提供场景；本地制造与履约责任只在与该场景直接相关时形成差异化。
- 不以战争、灾情或重建作常规销售钩子。仅在权威来源确认具体安置或重建需求时，低频讨论临时安居的安全、卫生、部署、维护与交付要求；不得暗示公司参与某项目，除非有可公开授权的事实。

## 表达校准

- 每项公司能力都要与当前语义承诺建立明确的证据关系：它要么直接支持必须答案，要么改变答案的强度、条件或责任边界。
- 表达强度不得超过资料能证明的范围；稳定能力与实时库存、交期、排产和项目配置分开处理。
- 维度用于选择当篇必要证据，不用于生成固定问法、核对清单或段落顺序；本规则不规定问题形式、清单或段落。
