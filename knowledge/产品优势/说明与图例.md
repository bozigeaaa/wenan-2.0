# 说明与图例

来源：原优势总表“说明与图例”。仅用于解释历史记录，不规定文案句式或发布口径。

| 字段 | 原定义 |
| --- | --- |
| 可信级A | 原编目认为是一手BOM、配置表或参数表 |
| 可信级B | 原编目认为是宣传册、卖点或二手口径 |
| 可信级C | 待核实、有冲突或假设性表述 |
| A- | 原表使用过该标记，但未单独定义；保持历史标记，不补造含义 |
| 状态 | 定稿、草稿、待补、过时，均是原文档状态 |
| 重要度 | P0核心、P1次要、P2辅助，仅为旧编目分类 |

A/B级和“定稿”不能替代当前证据核验；不同主张仍要分别检查来源是否实际支持。旧表关于默认现货、全境交付及营销句式的指令已删除。

来源编号见 [资产总目录](资产总目录.md)，参数差异见 [冲突与去重登记表](冲突与去重登记表.md)，品牌主体见 [企业基础概况](../深圳钧瀚科技有限公司企业基础概况.md)。文案执行规则以项目AGENTS.md及共享规则为准。
