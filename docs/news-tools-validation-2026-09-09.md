## 新闻检索实测的结果边界

2026-09-09 当次访问：Etimad 官方列表及具体公告详情可读；MEED 部分报道只能读取标题、日期和摘要；Google 新闻与 X 直接读取未完成。替代渠道找到公开信息，但没有筛出同时通过时效、事实复核与产品适配的合格新闻。其他渠道成功不能改写原受限渠道的状态；该记录也不是今后的可用性保证。

## 尚未覆盖的验证

- 没有在第二个 Windows 账号、macOS 或 Linux 上实际运行；这些环境提供同一 Python 入口和安装说明，仍需当地实测。
- 浏览器模式使用当前机器的 Edge 可执行文件和临时浏览器上下文；没有把个人浏览器登录状态或浏览器二进制打包。此次没有在空机器上重新下载浏览器组件。
- Humanizer 的文件完整性与规则测试不等于在所有宿主、所有模型上的改写效果保证；新用户按安装指南中的短文案示例检查实际调用。
- 抓取命令能运行，不保证每个站点可访问；Firecrawl 的账号与服务额度不随仓库共享。
