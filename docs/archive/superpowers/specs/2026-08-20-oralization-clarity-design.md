# 口播清晰度优化设计

## 目标

在不减少已核实信息、不改变专业受众默认知识水平的前提下，让口播稿更容易听懂，且不因口语化而变长。

## 修改范围

只调整 `script-oralization-rewriter` 与 B2B Humanizer 的表达职责，不调整事实核验、标题交接、专项路由或分镜流程。

## 规则

1. 口语化改写先完成信息排序：判断、原因、可执行动作。不得按资料罗列顺序直接展开。
2. 同一事实或条件组只解释一次；将抽象、书面词替换为具体说法，不为解释专业受众已知术语额外扩句。
3. 一句只承载一个主要判断或条件；只有能改善理解时才拆句。改写不得因口语化增加原稿篇幅。
4. Humanizer 仅删重复、替换书面词、调整停顿和修正不顺口句子；不得增加解释、转场或新句子，不得破坏前一步完成的信息排序与清晰表达。

## 验收

- 改写稿保留原稿全部已核实的结论、条件、因果强度、适用范围和资料出处。
- 改写稿不通过增加解释来换取易懂；长度不超过输入稿。
- Humanizer 不重新组织已完成的逻辑，不使文本回到说明书式表达。
- 现有口语化规则与 Humanizer 审校规则中均有对应、非重复的职责说明。
