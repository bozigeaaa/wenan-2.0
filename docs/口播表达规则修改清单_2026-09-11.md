# 口播表达规则修改清单

更新日期：2026-09-11

本轮已把“以平等、温和的提醒为主”写入项目规则，并同步修改生成入口、开头要求、Humanizer 和定稿检查。下表汇总本次讨论中确认的修改。

这份清单记录修改结果，不新增另一套写作规则。公共规则仍以 `AGENTS.md` 和共享规则文件为准，详细表达标准统一放在 `.agents/skills/references/expression-craft.md`。

## 一、已经修改的表达要求

| 项目 | 现在执行的规则 |
| --- | --- |
| 整体语气 | 以平等、温和的提醒为主，承接读者正在处理的事情，说明值得确认的细节及其作用。不预设读者犯错，不反复警告、纠正或指挥读者。 |
| 开头的“你／你的” | 删除强制出现要求。按交流需要自然使用；保留“脱离标题也能理解对象和场景”。第一句只设置悬念时，最迟第二句补足语境。 |
| 口语词 | 取消口语词配额和主动补入口头禅的要求。“说白了、其实、啊、呢、嘛、吧”等仍可按语境自然使用。 |
| 否定表达 | 删除指定否定词组的次数限制，不通过换近义词规避检查。连续使用“否定＋解释”等重复结构时，按整段意思调整；真实并列和必要条件对照可以保留。 |
| 容易产生训诫感的词句 | 口播默认避用“先别急着、不代表、可别、不能、当然”，以及带质问意味的“怎么……就……”。遇到时重新组织整句和相邻段落，不只换词。 |
| 必要的否定边界 | 资料明确规定禁止或不适用时，保留准确判断。语气温和，也要讲清必须满足的条件；不把必要条件改成可选建议。 |
| 改写示例 | 删除“比较实用的做法是→你先这样做”。原意相符时，“进行核对”可改成“确认一下”，“需求成立以后”可改成“确认需求之后”。 |
| 主语与动词 | 主语缺失、指代不明或责任不清时补足主语；已经清楚时不机械重复。不要求所有动词都改成具体动作指令，按原意和语境选择。 |
| 连接词 | 按转折、因果、条件、补充等真实关系使用。删除空泛铺垫，保留有作用的连接；不按词表机械删除或互换。真实流程保留必要顺序。 |
| 句子长短 | 按意思、主干和自然换气调整。能顺着说清的句子保留，不为缩短句子切断条件和逻辑。 |
| 新闻篇幅 | 取消“新闻只作一句背景”的限制。新闻可以承担关键证据，篇幅由本条判断需要决定，保留必要的主体、时间范围和适用条件。 |
| 定稿检查 | 统一检查理解是否顺畅、朗读是否自然、有无重复表达、语气是否平等温和，不再用代词、口语词或指定否定词组的数量判定合格。 |

“可以确认一下、顺便看看”只是可选表达，不会变成每段必用的新模板。正文仍要给出有证据的判断，不能全部写成提醒或泛泛的核对建议。

## 二、继续保留的要求

- 事实命题、主体、限定条件、因果强度和责任关系保持准确；不因语气调整而放大结论。
- 假设仍明确为假设；企业自述保留来源归属，不写成已经验证的效果或行业普遍情况。
- 不为口语感补造“很多人、大家都、常见情况”、项目经历或客户反馈。
- 一条文案兑现一个内容承诺，保留必要的比较、条件和证据。
- 禁用反问；全文设问最多两处，问句额度不要求用满。
- 结尾保留一个与本题有关的明确动作；用户要求无 CTA 时按要求结束。
- 篇幅继续执行现有弹性规则；分镜继续只拆分定稿，不重新改写文案。

## 四、验证结果与范围

### 规则检查

对 6 组相关检查共 65 项进行了修改前后对照：修改后 63 项通过，2 项失败与修改前一致，没有新增失败。

这两项仍要求旧的“约 300 字”，而当前篇幅规则已经采用“约 500 字”的弹性基准，分别位于：

- `tests/test_oral_style_contract.py` 的 `test_default_length_and_storyboard_scope`。
- `tests/test_triggered_generation_pipeline.py` 的 `test_default_oral_length_is_applied_without_dropping_evidence`。

它们属于既有的篇幅检查冲突，本次未更改篇幅规则或这两项检查。全量检查入口还受到现有新闻测试形式不兼容的影响，因此本轮验证结论限定在上述相关检查，不声称全量测试通过。

另外，已检查当前项目规则中的旧配额、强制开头代词、新闻一句话限制等残留，并通过改动格式检查。

### 五个短段落复测

复测覆盖到场日期、假设报价、企业自述、多个必要条件和明确不适用边界。结果中没有强制用“你”开头，也没有为口语配额补词；数量与配置条件、配送日期边界、假设身份、来源归属和“不适用”判断均有保留。

这些是有限事实下的短段落验证，能够检查本轮语气与事实边界目标，不等同于完整文案质量验证。个别样本仍有轻度重复或偏解释性表达，后续成稿继续按新标准检查。
