# 新用户使用指南

这份指南说明如何在新对话中使用项目。完整工作规则以 [AGENTS.md](../AGENTS.md) 和其中引用的共享规则为准；本指南不替代事实核验要求。

## 1. 下载后先打开项目

下载 GitHub 仓库的完整 ZIP 并解压，在 Codex 桌面版中打开项目文件夹。该文件夹应同时包含 AGENTS.md、README.md、knowledge、.agents、scripts 和 docs；.agents 是隐藏目录，也要保留。

新对话要建在这个项目内，Codex 才能读取本项目的规则和资料。单独打开一个不关联项目的空白对话，不会自动知道项目放在哪里。

第一次需要了解工作规则时，可以说：

> 请阅读 docs/新用户使用指南.md 和 AGENTS.md，按本项目规则工作。

## 2. 启动新闻收集

在项目内新建一个专门收集新闻的对话，说：

> 收集新闻

Codex 会读取项目内 daily-industry-news 技能，检查本机可用工具，完成首轮新闻发现、逐条核验和 HTML 日报，并在当前用户自己的 Codex 中启用自动化。已有匹配任务时复用，避免重复创建。缺少抓取环境时按项目说明准备，读取某个网站受限时换用可用的公开来源。

**每轮必须双工具检索。** 默认用 Scrapling 检查网站、公告及原文，用 Firecrawl 搜索和补漏；两边分别留记录，合并去重后核验。某个工具不可用时换另一种实际可用工具补足，仍不足两种则说明本轮未完成。两个工具不等于两个独立事实来源。

仅希望临时运行一次，可以明确说：

> 只收集这一次新闻，不启用自动化。

下载文件本身不会启动定时任务；首次指令和实际注册步骤需要在使用者自己的 Codex 中完成。

## 3. 每天什么时候收到新闻

默认每天北京时间09:00和14:00各启动一轮收集与核验，完成后在新闻对话中汇报。

上午和下午分别记录完成状态。下午会增量更新当天日报，上午完成不会跳过下午；同一批次重复触发时不重复推送。下一轮覆盖上次成功采集后的变化，并向前重叠回查24小时补漏；重复报道合并，实质性新进展单独标明。

启用后不必每天重新说“收集新闻”，也不必打开那个新闻对话。电脑需要开机、Codex 保持运行并联网，项目文件仍在原位置。应用关闭期间不采集；错过的内容合并到下一次可运行的计划批次，不在重新打开时高频轮询。整点是任务启动时间，汇报在采集与核验完成后发出。

调整时间或暂停时，在 Codex 中直接说明要求，例如“把新闻收集改为每天北京时间10点一次”或“暂停每日新闻收集”。每位用户使用自己的账号、工具权限和额度。

## 4. 查看 HTML 日报

完成消息会附可点击的本地 HTML 文件。最新文件为 outputs/daily-news-demo.html，可离线打开；当日归档为 outputs/daily-news-YYYY-MM-DD.html，结构化数据为 outputs/news/YYYY-MM-DD.json。

- 收录日期：可切换最近15个自然日。明天生成日报后，今天的记录仍可按日期查看。
- 核验状态：默认显示已核验新闻；切换为“全部新闻与线索”可查看完整收录记录。
- 查看核验依据：显示核验时间、实际来源、结论及尚缺的证据。
- 产品筛选：只展示有实际结合依据的方向；没有直接适配产品的新闻仍可作为行业信息收录。

“未通过核验”表示本轮已执行查证，但关键证据仍不足；具体缺口写在该条记录中。它不等于新闻必然虚假，也不能作为已经确认的事实直接写稿。新闻事实核验与产品适配分别判断。

上午、下午合并更新同一天的日报，保留当天稳定编号；跨天按日期归档。页面最多展示最近15天，历史数据文件继续保存在本地。

## 5. 把选题交给写稿对话

新闻收集与文案生成分开使用：

1. 在日报选中新闻，按需要选择适配产品，点击“复制选题指令”。
2. 在同一个项目内新建专门写文案的对话，粘贴指令。
3. 写稿对话依据新闻来源、核验时间和产品资料继续判断，先生成标题方向；用户选定方向后再生成完整文案。
4. 文案确认后，需要分镜时再说“生成分镜”。

复制内容包含新闻编号、来源、核验结论及产品结合依据，用户无需手动整理。证据不足的记录对应“复制核验线索”，先补证据，不直接生成标题或正文。新闻收集对话不会自动向写稿对话发送消息。

## 6. 规则在哪里

| 用途 | 入口 |
| --- | --- |
| 项目总规则、资料与事实边界 | [AGENTS.md](../AGENTS.md) |
| 新闻收集、两次调度、核验和日报生成 | [daily-industry-news](../.agents/skills/daily-industry-news/SKILL.md) |
| 文案、标题、修改和分镜路由 | [wenan-skill](../.agents/skills/wenan-skill/SKILL.md) |
| 本地自动化运行与自检说明 | [本地新闻日报自动化](local-news-automation.md) |
| 公司资料导航 | [AI资料导航索引](../knowledge/AI资料导航索引.md) |

首次使用成功的判断：已有本机启用的新闻自动化、首轮 HTML 能打开、每条收录新闻都有核验时间和依据。未能注册、环境不可用或采集失败时，应由 Codex 说明具体原因，不能把文件已下载当作自动化已经启用。
